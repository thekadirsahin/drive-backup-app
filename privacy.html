Privacy policy

This policy applies to Kadir Drive Append Backup, a personal desktop backup utility operated by its account owner.

Google data accessed and purpose

The utility reads Drive folder and file metadata, including names, IDs, parent folders, file sizes and available checksums, to identify missing items, detect conflicts and verify backups. It uploads local file contents only to the owner’s designated Google Drive folders. It does not download existing Drive file content.

Permissions and limits

Google OAuth may grant broad Drive access. The backup implementation limits operations to metadata reads and creating missing folders and files. It does not use overwrite, delete, sharing or permission-change operations.

Storage and security

OAuth credentials and refresh tokens are stored on the owner’s computer in restricted-permission configuration files. Local journals and logs contain file paths, metadata, checksums and outcomes. Backup file contents are stored in the owner’s Google Drive account and remain subject to the owner’s access settings and Google’s policies. This public website stores no backup data or OAuth credentials.

Sharing and notifications

The utility does not sell Google user data, provide it for advertising or send backup contents to AI models. Google receives the metadata and uploaded contents needed to provide Drive storage. If enabled, a private notification service receives backup status, counts and brief error information, but not backup file contents or OAuth credentials. The website is hosted by GitHub Pages; GitHub may process ordinary website request information under its own privacy policy.

Retention and control

Backups remain in Drive until the owner separately removes them; the utility never automatically deletes them. Local logs and credentials remain until the owner removes them. The owner can stop scheduled backups and revoke OAuth access in Google Account permissions. Revocation stops future authorized access but does not delete existing backups.

Contact

Contact the operator through repository issues. Do not post confidential data in public issues.
