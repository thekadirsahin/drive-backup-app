Kadir Drive Append Backup

A private, owner-operated desktop utility that adds missing local files to designated folders in the owner’s Google Drive account.

The backup is one-way, local to Drive. Existing destination files are skipped or reported as conflicts. The utility does not download Drive file content, replace existing files, or delete local or remote files. It preserves the local folder structure and verifies the result.

This is a personal-use application, not a public backup service. This website contains only application information and policies, never backup files or credentials.
